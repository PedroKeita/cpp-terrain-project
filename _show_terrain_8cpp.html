Detailed Description

Implementation of function to generate and display 3D terrain using libigl.

This module constructs a triangular mesh based on a height matrix and displays it in an OpenGL viewer provided by the LibIGL library.

void showTerrain ( const Eigen::MatrixXd &  heights)

Displays a 3D mesh based on a heightmap.

Launches interactive 3D terrain viewer.

The function receives a height matrix (heights), converts it to a set of 3D vertices, constructs triangulation to form a mesh, and applies coloring based on altitude. Then uses LibIGL to render the terrain interactively.

Parameters
heightsMatrix (Eigen::MatrixXd) containing terrain heights. Each element heights(y, x) represents elevation at point (x, y).
Note
The terrain is automatically scaled to fit the viewer.
Colors are interpolated based on the average height of each triangle.
