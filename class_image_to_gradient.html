Detailed Description

Converts QImage to gradient matrices using Sobel operator.

This class provides static methods to compute gradient fields from QImage objects using OpenCV's Sobel operator.

Convert QImage to gradient matrices.

Parameters
imgInput image (will be converted to grayscale)
dxOutput matrix for gradient in X direction
dyOutput matrix for gradient in Y direction
Note
The input image is converted to grayscale using luminance formula: 0.299*R + 0.587*G + 0.114*B
Uses 3x3 Sobel kernel for gradient computation
Output matrices are resized to match image dimensions
