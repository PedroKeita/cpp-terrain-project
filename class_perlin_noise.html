Detailed Description

Generates 3D Perlin noise with fractal octave support.

Deterministic noise generation useful for procedural terrain, textures, and natural effects.

PerlinNoise::PerlinNoise ( )

Classic Ken Perlin permutation.

Default constructor using Ken Perlin's classic permutation.

This permutation table produces standard deterministic noise. The internal vector p contains 512 elements where the first 256 are duplicated at the end, facilitating wrap-around operations.
